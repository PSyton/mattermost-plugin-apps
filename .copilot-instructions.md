# GitHub Copilot Instructions for Mattermost Apps Plugin Refactoring

## Project Context

This is a **2GIS fork** of the Mattermost Apps Plugin undergoing major refactoring (v2.0.0).

### Key Changes:
- **Plugin ID**: `com.mattermost.apps` → `ru.2gis.apps`
- **Bindings Model**: Client-initiated requests → Server-side caching with on-demand refresh
- **Locations**: Only `/command` supported (no post_menu, channel_header, in_post)
- **Forms**: Modal forms removed, only slash command autocomplete
- **Health Check**: Mandatory `/health` endpoint for all apps

## Current Branch Strategy

Working in feature branch for all changes. Each major step should be a separate commit.

## Code Style and Conventions

### Go Code Standards
- Follow existing project structure and naming conventions
- Use descriptive variable names
- Add comprehensive comments for public APIs
- Use structured logging with fields: `log.With("key", value)`
- Error handling: wrap errors with context using `errors.Wrap(err, "context")`

### Naming Conventions
- Plugin ID: `ru.2gis.apps` (everywhere)
- Constants: Use existing pattern (e.g., `path.Health`, `LocationCommand`)
- Types: PascalCase (e.g., `AppActivityTracker`, `BindingsCache`)
- Functions: camelCase private, PascalCase public
- Files: snake_case (e.g., `app_activity_tracker.go`)

### 4. Health Check Implementation (Этап 8)

**CRITICAL: Health check is MANDATORY, not optional**

**Add constant:**
```go
// In apps/path/paths.go
const Health = "/health"
```

**Activity Tracker pattern:**
```go
// In server/proxy/app_activity_tracker.go

func (t *appActivityTracker) performHealthCheck(app apps.App) {
    // ALWAYS use fixed path - no manifest checks
    healthCheckCall := apps.Call{
        Path: path.Health, // NOT from manifest!
    }
    
    // 5 second timeout
    ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
    defer cancel()
    
    // Call and log result
    resp := t.proxy.call(r, &app, healthCheckCall, &cc)
    
    if resp.Type == apps.CallResponseTypeError {
        log.Warnf("Health check failed - app may not implement required /health endpoint")
    }
}
```

**DO NOT check**: `if app.OnHealthCheck == nil` or `app.Manifest.OnHealthCheck`

## Common Mistakes to Avoid

### ❌ DON'T:
- Add periodic refresh to bindings cache
- Check `app.OnHealthCheck` or `app.Manifest.OnHealthCheck`
- Use `com.mattermost.apps` or `com.mattermost.apps.v2` namespace
- Add Start/Stop methods to bindingsCache
- Allow locations other than `/command`
- Add modal form support
- Use `BindingsCacheInterval` configuration

### ✅ DO:
- Use `ru.2gis.apps` everywhere
- Make health check mandatory with fixed `/health` path
- Update cache only on-demand (install/uninstall/enable/disable/manual)
- Use `path.Health` constant
- Record activity on every app call
- Clear activity tracker on app uninstall
- Log errors for apps without `/health` endpoint

## Bindings Cache Specifics

### Refresh Triggers

Bindings cache should ONLY refresh on:

1. **App lifecycle events:**
   - `InstallApp()` - after successful install
   - `UninstallApp()` - after uninstall
   - `EnableApp()` - after enable
   - `DisableApp()` - after disable

2. **Explicit requests:**
   - `CallResponse.RefreshBindings = true` - app requests refresh
   - `/apps refresh-bindings` command - admin manual refresh
   - `POST /api/v1/bindings/refresh` endpoint - API refresh

3. **Initialization:**
   - `OnActivate()` - plugin startup (InitCache)

### NO Automatic Periodic Refresh

```go
// ❌ WRONG - do not implement
func (bcs *bindingsCacheService) Start() {
    go func() {
        ticker := time.NewTicker(interval)
        for range ticker.C {
            bcs.RefreshCache() // NO!
        }
    }()
}

// ✅ CORRECT - only init
func (bcs *bindingsCacheService) InitCache() {
    bcs.RefreshCache() // Only once on startup
}
```

## Health Check Specifics

### Requirements for App Developers

Every app MUST implement:

```go
func (a *MyApp) Call(creq apps.CallRequest) apps.CallResponse {
    switch creq.Path {
    case path.Health: // REQUIRED!
        return apps.NewTextResponse("OK")
    // ...other paths...
    }
}
```

### Plugin Behavior

- Call `/health` every N minutes of inactivity (default: 5)
- Timeout: 5 seconds
- Log warning if fails, but don't disable app
- No checks if endpoint exists - always call it
